# Lode map

- [summary.md](summary.md): what better-agent is, with a data-flow diagram
- [terminology.md](terminology.md): domain terms
- [practices.md](practices.md): invariants, adding a source, testing, CLI design (clig.dev), dependencies
- index/
  - [summary.md](index/summary.md): bta.db schema, FTS, links, search fallback
  - [ids.md](index/ids.md): session and message id derivation, prefix resolution
- sources/
  - [summary.md](sources/summary.md): the import pipeline and shared part normalization
  - [claude-code.md](sources/claude-code.md): reading the jsonl files and incremental import
  - [opencode.md](sources/opencode.md): v2 tables, dual-era fallback, auto-links
- handoff/
  - [summary.md](handoff/summary.md): intent spine, pack layout, output targets, handoff auto-links
  - [switch.md](handoff/switch.md): `bta switch`, which picks a session and launches the other agent with its pack
- plans/
  - [backlog.md](plans/backlog.md): known gaps (empty)
  - [share.md](plans/share.md): shaped pitch, not built yet. `bta share` writes one HTML page of a session for teammates, with redaction.
  - [switch-to-option.md](plans/switch-to-option.md): implemented in 0.7.0; `bta switch --to` makes the destination explicit.
  - [switch-subdirectories.md](plans/switch-subdirectories.md): implemented in 0.7.1; the `bta switch` picker also offers sessions from directories below the current one.
  - [resume.md](plans/resume.md): implemented in 0.7.2; `bta resume` reopens a session in its own agent.
- tmp/: session scraps (git-ignored)
